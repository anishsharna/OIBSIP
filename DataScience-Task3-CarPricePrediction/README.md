# Car Price Prediction

Predict the selling price of a used car using machine learning regression.

## Technologies
Python, pandas, NumPy, Matplotlib, Seaborn, scikit-learn, Jupyter Notebook.

## Workflow
- Clean and explore the car dataset.
- Prepare features and encode categorical variables.
- Train regression models.
- Evaluate predictions using regression metrics.
